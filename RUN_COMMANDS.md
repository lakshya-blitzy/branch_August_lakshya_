# COMPLETE RUN COMMANDS FOR TESTINIUM-QA PROJECT

## Prerequisites
- Node.js v18.18.0 or higher
- Maven 3.x
- Java 8 or higher

## Quick Start Commands

### 1. Run Complete Test Suite via Maven (Recommended)
```bash
mvn clean test
```

### 2. Run JavaScript Tests Directly
```bash
npm test
```

### 3. Run JavaScript Tests with Coverage
```bash
npm run test:coverage
```

### 4. Start Node.js Server Directly
```bash
node src/main/js/server.js
```
